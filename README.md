## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/project_dashboard.git
```

Go to project folder:

```bash
cd project_dashboard
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Run Project

Start development server:

```bash
npm start
```

Open:

```bash
http://localhost:3000
```

---

## 🏗 Build For Production

```bash
npm run build
```
